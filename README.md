# Planning Imagerie

Outil interne de brouillon de planning pour un service d'imagerie médicale — front-end 100% statique (HTML/CSS/JS vanilla, zéro dépendance, zéro build).

Ce dépôt ne contient que le code de l'application. Les données réelles (personnel, planning, congés, gardes) ne sont jamais stockées ici — elles vivent dans un dépôt privé séparé, accédé par l'application au moment de l'exécution.
